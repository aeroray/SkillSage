## What's New · 本次更新

### 🌐 在线更新与国内加速 · Updates & China Access

- 检查更新时并发请求多个 GitHub 镜像节点与 GitHub 直连，取最快且返回有效清单的源，国内网络下也能正常检查更新。
  Update checks now race several GitHub mirror nodes against direct GitHub concurrently and use the fastest source returning a valid manifest, so checks work from mainland China.

- 安装包下载同样走胜出的镜像；安装包仍由 Tauri updater 用公钥做 minisign 签名校验，被篡改的镜像只会导致签名失败，无法安装。
  Installer downloads also use the winning mirror, while the Tauri updater still verifies the minisign signature against the configured public key, so a tampered mirror only produces a signature failure.

- 修复检查更新未使用「安全与连接」中已配置代理的问题。
  Fixed update checks ignoring the proxy configured in Settings.

- 设置页会显示最近一次检查实际使用的源，网络问题时更容易定位。
  Settings now shows which source served the most recent check, making network problems easier to diagnose.

### 🧰 技能分发 · Skill Distribution

- 内置主流 AI 工具的技能目录注册表并自动检测本机已安装的工具，替代原先只支持两个工具的固定适配。
  Added a built-in registry of mainstream AI tools' skills directories with automatic detection of what is installed, replacing the previous fixed two-tool adapters.

- 修正 Work Buddy 的技能目录为 `~/.codebuddy/skills`，并清理旧版本写入无效目录的链接。
  Corrected the Work Buddy skills directory to `~/.codebuddy/skills` and cleaned up links written to an invalid directory by earlier versions.

- 可针对每个工具单独设置是否「读取公共技能目录」；开启后不再向该工具分发，并移除已有链接。
  "Reads the shared skills directory" can now be set per tool; enabling it stops distributing to that tool and removes its existing links.

- 选择技能目录改为系统原生目录选择器，并可复制路径、直接打开目录。
  Choosing a skills directory now uses the native directory picker, with actions to copy the path or open the folder.

### 🎨 界面与体验 · Interface and User Experience

- 应用自绘标题栏，页面名称与页面操作并入标题栏，各页面不再重复绘制页头。
  The app now draws its own title bar, with the page name and page actions moved into it, so pages no longer repeat a header.

- 设置页重构为左侧分区导航加右侧内容区，替代原先需要左右两列来回查找的卡片布局。
  Settings was rebuilt as a section nav with a single content pane, replacing the card layout that required scanning two columns.

- 统一所有弹窗为同一套公共组件与视觉规范。
  Unified every dialog behind one shared component and visual specification.

- 技能行可点击名称直接打开详情；分发状态压缩为圆点加计数，行高不再随已安装工具数量增长。
  Clicking a skill name now opens its detail; distribution status is condensed to dots plus a count, so row height no longer grows with the number of installed tools.

- 技能列表改为「勾选后显示批量操作栏」，并显示每个操作实际会影响的技能数量。
  The skills list now shows a batch action bar once anything is selected, with each action showing how many skills it will actually affect.

- 页面不再整体滚动，只有列表区域滚动，滚动时筛选条件与列头保持可见。
  Pages no longer scroll as a whole; only list regions scroll, keeping filters and column headers visible.

- 修复切换主题色后部分文字仍显示为青色的问题。
  Fixed text still appearing teal after switching the theme accent.

- 修复技能商店卡片中「下载量」与操作按钮对齐不一致的问题。
  Fixed the store card's download count misaligning when a card also showed the repository button.

### 🛡️ 稳定性与安全 · Reliability & Security

- 修复技能内容指纹在部分情况下计算不一致，导致更新检查长期误报「有更新」的问题。
  Fixed content fingerprints being computed inconsistently in some cases, which made update checks report a permanent false positive.

- 修复卸载技能时先删除内容后写入记录、失败后残留记录导致无法重新安装的问题。
  Fixed uninstalling a skill deleting content before recording it, which could leave a stale record that blocked reinstalling.

- 修复 Windows 上主目录路径含 `&` 等字符时，创建技能链接会截断路径并执行多余命令的问题。
  Fixed skill-link creation on Windows truncating the path and executing extra commands when the home path contained characters such as `&`.

- 修复快速连续操作时较早的请求覆盖较新结果的问题，以及部分安装失败没有任何提示的问题。
  Fixed earlier requests overwriting newer results during rapid interaction, and some failed installs giving no feedback at all.

- 批量检查与更新技能改为并发执行，单个技能失败不再中断整批。
  Batch checking and updating now run concurrently, and one failing skill no longer aborts the whole batch.
