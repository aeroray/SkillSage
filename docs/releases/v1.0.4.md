## What's New · 本次更新

### 🔄 应用内更新 · In-App Updates

- 更新界面现在会显示本次更新的完整发布说明，安装前就能看到改了什么；并显示「当前版本 → 新版本」，一眼看出这次升级的跨度。
  The update panel now shows the full release notes before installing, and displays "current → new" version so the size of the jump is visible at a glance.

- 修复安装 GitHub 链接技能时，预览和安装可能读取到不同提交的问题。此前检查地址时会解析出具体提交用于预览，但安装时会重新解析分支——若该分支在预览与点击安装之间被推送了新内容，实际安装的就是用户从未审阅过的内容。现在安装固定到预览时的那个提交。
  Fixed a GitHub-URL install reading a different commit than the one previewed. The check resolved a commit to build the preview, but the install re-resolved the branch — so content pushed in between was installed instead of what the user reviewed. The install is now pinned to the previewed commit.

- 修复一个无法读取的技能条目会导致整个仓库的技能列表为空的问题；现在会跳过该条目并继续列出其余技能。
  Fixed one unreadable skill entry hiding a repository's entire skill list; the bad entry is now skipped and the rest are still listed.

### 🧩 技能分发筛选 · Filtering by Distribution

- 「分发」筛选改为直接点击工具徽章：可多选（取并集），并提供「反选」查看未分发到所选工具的技能。此前的下拉加结果模式需要先给问题命名才能筛选。
  The 分发 filter is now the tool badges themselves: select several for a union, plus 反选 to see skills *not* distributed to the selection. The previous dropdown-plus-outcome-mode required naming the question before asking it.

- 工具徽章行可横向滚动且不显示滚动条，滚轮与键盘仍可操作。
  The badge row scrolls horizontally without a visible scrollbar; the wheel and keyboard still work.

### 🧩 采纳技能 · Adopting Skills

- 工具条精简为一行，控件顺序与「我的技能」一致：左侧全选，右侧「打开共享目录」与主操作。目录不再显示为可点击的路径文本，改为按钮，路径仍可在悬停提示中查看。
  The toolbar is now one line with the same control order as 我的技能: select-all on the left, 打开共享目录 and the primary action on the right. The directory is a button rather than clickable path text, with the path still available in its tooltip.

- 修复崩溃后残留的备份目录会被列为可采纳技能的问题。被顶替的目录会先改名备份、成功后才删除，若在这两步之间崩溃，该备份会留在公共目录里，并被当成一个可采纳的技能显示出来。
  Fixed a leftover backup directory being listed as an adoptable skill. A displaced directory is renamed aside and deleted only after the install succeeds; a crash in between left that backup in the shared directory, where it appeared as an adoptable skill.

### 🎨 界面与字号 · Interface and Type

- 统一全站字号为四档（12 / 14 / 16 / 18px），并修复筛选按钮字号比它旁边的标签还大的问题。
  Unified the type scale to four steps (12 / 14 / 16 / 18px), and fixed filter chips rendering larger than the label beside them.

- 修复「检查全部更新」在检查过程中没有任何逐行反馈的问题；现在每个远端技能都会显示检查中的状态。
  Fixed 检查全部更新 giving no per-row feedback while running; every remote skill now shows its checking state.

- 技能商店加载时显示十个骨架卡片，与加载完成后的网格布局对齐。
  The store now shows ten skeleton cards while loading, matching the grid that replaces them.

- 修复技能商店在切换技能时短暂显示上一个技能信息的问题；在该时间窗内点击安装会装错技能。
  Fixed the store briefly showing the previous skill's details while switching; clicking install in that window installed the wrong skill.

- 修复筛选、导入等操作在连续快速点击时可能重复执行或互相清除加载状态的问题。
  Fixed rapid repeated clicks on filters and import actions causing duplicate runs or one action clearing another's loading state.

### 🛠️ 技能目录与工具 · Skill Directories and Tools

- 修复「打开目录」在目录不存在时毫无反应的问题；现在会打开最近的存在上级目录，并说明实际打开了哪一个。
  Fixed 打开目录 doing nothing when the directory does not exist; it now opens the nearest existing parent and reports which path it opened.

- 修正 OpenAI Codex CLI 条目的文档出处（此前指向 Cursor 的文档）。该条目的路径本身未变，仍标注为「路径未核实」。
  Corrected the OpenAI Codex CLI entry's documentation source, which pointed at Cursor's docs. The path is unchanged and still marked 路径未核实.

### ⚡ 性能 · Performance

- 技能商店复用同一个 HTTP 连接，搜索不再每次重新建立连接（DNS 与 TLS 握手此前是打字搜索的主要开销）；并缓存已打开的技能详情，重复打开不再重新抓取和解析页面。
  The store reuses one HTTP connection instead of rebuilding it per search — the DNS and TLS handshake used to dominate typing-paced searches — and caches opened skill details so reopening does not refetch and reparse the page.

### 🛡️ 稳定性 · Reliability

- 修复本地导入选择「导入为新名称」时，冲突检查查的是源名称而非实际写入名称的问题；此前目标位置若已有同名目录会跳过接管确认。
  Fixed the local import conflict check testing the source name instead of the name actually written when renaming; a directory already at the rename target previously skipped the takeover prompt.

- 修复设备同步导入时，弹窗关闭后仍在进行的预览请求会写入已关闭弹窗状态的问题。
  Fixed a sync-import preview response writing into a closed dialog's state.
