## What's New · 本次更新

### 🪟 弹窗密度 · Dialog Density

- 弹窗不再比它背后的窗口「更松」。此前弹窗是全应用唯一自带一套间距刻度的表面（内边距 `24/20`、`24/24`），而工具条、卡片头、列表行都是 `20/16`；结果是弹窗头部到主体之间空出 `45px`，而主窗口的工具条到列表只有 `33px`——同一个界面里两套节奏。现在弹窗三段统一为 `20/16`，头部到主体同样是 `33px`。
  Dialogs are no longer roomier than the window behind them. They were the only surface in the app with their own spacing scale (24/20, 24/24) while the toolbar, card header and list rows all used 20/16 — so the gap from a dialog's header to its body was 45px where the main window's toolbar-to-list gap was 33px, two rhythms in one interface. All three bands now use 20/16, and the header-to-body gap is 33px.

- 弹窗右上角的关闭按钮与标题对齐。按钮高 `32px`、标题 `18px`，此前按钮比标题中心低 `3px`；现在相差 `1px`。
  The dialog close button is aligned with its title. The button is 32px and the title 18px; the button previously sat 3px below the title's centre, and now differs by 1px.

- 提示气泡（Tooltip）的阴影改用主题的浮层阴影。此前它用的 `shadow-md` 并不在主题里，会落到一套硬编码的黑色阴影上——不跟随主题，浅色模式下偏灰、深色模式下不会加深。现在与弹窗、下拉菜单、Toast 使用同一个阴影。
  Tooltip shadows now use the theme's overlay shadow. The `shadow-md` it used before is not defined by the theme and fell back to a hardcoded black that does not track it — greyish in light mode and not deepening in dark. It now shares the same shadow as dialogs, dropdowns and toasts.

### 🔤 文字与措辞 · Text and Wording

- 同一个目录不再有四种叫法。「共享技能目录」「共享目录」「公共技能目录」「公共目录」混用，现在统一为「共享技能目录」／「共享目录」。设置页与技能页的相关说明、徽章和勾选项都会跟着变。
  The same directory no longer has four names. 共享技能目录, 共享目录, 公共技能目录 and 公共目录 were used interchangeably; the UI now says 共享技能目录 / 共享目录 throughout, including the related descriptions, badges and checkbox labels in Settings and 我的技能.

- 「已最新」改为「已是最新」。此前这是全站唯一的截断写法，其他地方都写全（「已是最新版本」「均为最新」）。
  The 已最新 filter chip now reads 已是最新. It was the only clipped form in the app; everywhere else spells it out.

- 排序按钮的提示改为直接说明结果顺序：「名称 A→Z」／「名称 Z→A」。此前写「技能名称从后往前」，需要读者自己判断「后」是哪一端。
  The sort button's tooltip now states the resulting order — 名称 A→Z / 名称 Z→A — instead of 技能名称从后往前, which left the reader to work out which end 后 meant.

- 「检查全部更新」在没有可检查的远端技能时，不再报「已检查 0 个技能，均为最新」并配绿色对勾。现在会说明没有可检查的项，以及原因（本地导入和内置技能没有远端来源）。
  When 检查全部更新 finds no remote skills to check, it no longer reports "已检查 0 个技能，均为最新" under a green check. It now says there is nothing to check and why: locally imported and built-in skills have no remote source.

### 🧭 一致性 · Consistency

- 输入框、下拉菜单和 Toast 现在各自声明实际渲染的字号，不再依赖继承。此前输入框声明了 `16px`（由 `md:` 断点覆盖为 `14px`），下拉容器和 Toast 容器则完全没有声明、继承到 `16px` 正文大小——它们内部的每一项恰好都声明了 `14px`，所以**看起来**没有问题，但任何后加进去的内容都会继承错误的大小。渲染结果与声明值现在一致。
  Inputs, dropdowns and toasts now each declare the size they actually render instead of relying on inheritance. The input declared 16px (overridden to 14px by the `md:` breakpoint), while the dropdown and toast containers declared nothing and inherited the 16px body size — every item inside them happened to declare 14px, so nothing *looked* wrong, but anything added later would inherit the wrong size. Declared and rendered values now match.
