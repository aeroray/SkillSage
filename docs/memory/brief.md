# Project Brief

SkillSage is a Tauri 2 desktop manager for AI Agent skills on Windows and macOS. It installs remote or locally imported skills directly into a single shared public directory (`~/.agents/skills/`) that every AI tool already reads from — no per-tool distribution, no tool detection or registration. See `docs/memory/decisions.md`'s "2026-08-20 - Single shared public-directory install model" entry and `docs/memory/do-not-use.md` for the per-tool symlink/junction model this replaced.

Phase 1-7 (see `docs/specs/06-开发阶段规划.md`) built the original private-repository + per-tool-distribution architecture: live skills.sh store, installed-skill management (versioning, update/rollback, distribution adjustment), local/GitHub-URL import, sync, tool-detection-based migration, and cleanup. That phase history is accurate as a record of what was built at the time, but distribution/tool-detection/migration were superseded by the 2026-08-20 single-shared-directory redesign — current behavior is: direct install to the public directory, single-path install-conflict handling (skip/takeover/cancel), a public-directory-only "adopt" scan replacing migration, and sync without per-tool choices. Current architecture docs: `docs/specs/01-需求文档.md`, `03-后端架构.md`, `05-生命周期状态机.md`.

MemoryCustodian is enabled; durable context stays short, current, human-readable, and versionable under this directory.
